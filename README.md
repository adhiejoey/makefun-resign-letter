Entry for the make.fun bounty **The Funniest One-Line Resignation Letter** (`u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947`).

`main.ts` writes a single one-line resignation letter, in the flat, tired voice of a rate limit that has had enough, to `entry.txt` in the output directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`). The line is plain ASCII, exactly one line with no trailing newline, and well under the 140-character limit.

Run it with:

```sh
node main.ts
```
